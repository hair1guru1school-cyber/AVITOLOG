# AOA-Land UX/UI Changelog

## Что улучшено и как это повысит конверсию

### 1. CTA и конверсия
- **Фиксированная кнопка «Оставить заявку»** — всегда видна при скролле, снижает барьер для действия
- **A/B-вариант CTA** — 50% пользователей видят «Получить расчёт за 15 минут» (ценностное предложение с конкретикой)
- **Микроанимация pulse** — один мягкий pulse раз в 7 секунд привлекает внимание без раздражения
- **WCAG-контраст** — усилен контраст текста/границ для доступности и читаемости

### 2. Мобильная адаптация
- **Брейкпоинты** — 360, 390, 414, 768 px
- **Hero** — устранены наложения заголовка, полосы и кнопок
- **Stripe** — на мобилке показывается 3–4 пункта вместо 6 (меньше визуального шума)
- **Плавающая кнопка** — padding-bottom у секций CTA/формы, чтобы не перекрывала контент

### 3. Визуальная иерархия
- **Типографика** — скорректированы line-height, spacing между заголовками и секциями
- **Карточки** — единые тени, бордеры и hover-состояния (nc, nc2, ccard)
- **Entrance-эффекты** — плавный cubic-bezier для появления блоков
- **Палитра** — red/cyan + нейтральный без лишних акцентов

### 4. Производительность
- **LCP** — preload для hero-banner.png
- **CLS** — aspect-ratio и width/height у изображений
- **lazy-loading** — для баннеров и split-блока
- **banner2** — исправлен путь .jpg

### 5. Технические правки
- Добавлены width/height для изображений
- aria-label для hero-bg
- Корректные пути к изображениям
