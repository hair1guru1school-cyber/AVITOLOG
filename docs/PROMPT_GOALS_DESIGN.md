# Промпт: Дизайн вкладки ЦЕЛИ

## Статус: РЕАЛИЗОВАНО ✓

## Задача
Сделать дизайн вкладки ЦЕЛИ **точно таким**, как на референсных скриншотах.

## Ключевые элементы дизайна

### 1. Общий стиль
- **Тёмная тема** с эффектом звёздного/космического неба (звёзды, туманности)
- **Неоновое свечение** на элементах — границы и тени в цветах: фиолетовый, зелёный, оранжевый, голубой
- **Полупрозрачные панели** с яркими неоновыми рамками
- **Современный футуристический** вид

### 2. Навигация сверху (ЦЕЛИ активна)
- Кнопка ЦЕЛИ подсвечена **по всему контуру** голубым неоном (не углы, а вся кнопка)
- Иконка мишени + текст "ЦЕЛИ" в одном блоке

### 3. Карточки KPI (верхний ряд)
- **35 НОВЫХ** — фиолетовое/розовое свечение
- **47 В РАБОТЕ** — бирюзовое/зелёное свечение  
- **19 ПРОДАНО** — оранжевое свечение
- **1 260 000 P ВОРОНКА** — зелёное свечение, иконка воронки

### 4. Кнопки действий
- **+ ПРОЕКТ** — зелёное свечение
- **ВСЕГО 32** — голубое, с иконкой чекбокса
- **ПРОДАНО 6** — оранжевое, с иконкой стрелки

### 5. Секции недель (1 НЕДЕЛЯ, 2 НЕДЕЛЯ, 3 НЕДЕЛЯ)
- Полупрозрачный тёмный контейнер с голубым неоном по краю
- Таблица: **ДАТА | ПРОЕКТ | КП ▼ | СТАТУСЫ | КАСАНИЯ | X**
- Статусы как цветные теги: КП (оранжевый), Переговоры (синий), Счет, Договор и т.д.
- Внизу каждой секции: **+ Добавить проект** с иконкой меню
- Значение КП с выпадающим списком (▼) для вариантов

### 6. Блоки ПРОДАНО и В РАБОТЕ (в два столбца)
- **ПРОДАНО** — фиолетовое свечение, иконка графика, итог (375.000 P)
- **В РАБОТЕ** — оранжевое свечение, иконка огня, **ОБЩИЙ ПОТЕНЦИАЛ: 1 000 000 P**
- Список проектов с датой и суммой
- **+ Добавить проект** в каждом блоке
- Иконка X для закрытия/удаления виджета (если два блока)

### 7. АРХИВ
- Голубая/фиолетовая рамка, иконка папки
- Список: дата | название | иконка обновления (C)
- Примеры: Кирпин Завод, Бетон Юг

### 8. Детали
- Все панели: `border-radius`, `box-shadow` с цветным свечением
- Фон секций: `rgba` тёмный, полупрозрачный
- Акцент на визуальную согласованность: неон, градиенты, мягкие тени
