# ПРОМПТ: Макет страницы ЦЕЛИ — строгий layout

## Общая структура (сверху вниз)

```
┌─────────────────────────────────────────────────────────────┐
│  [KPI1]  [KPI2]  [KPI3]  [KPI4]   ← 4 карточки в ряд        │
├─────────────────────────────────────────────────────────────┤
│  ПРОДАНО  │  Неделя 4  │  В РАБОТЕ                          │
│  (левая   │  Неделя 3  │  (правая                            │
│   колонка)│  Неделя 2  │   колонка)                          │
│           │  Неделя 1  │                                      │
│           │  (центр,   │                                      │
│           │  4 блока   │                                      │
│           │  вертикально)                                     │
├─────────────────────────────────────────────────────────────┤
│  АРХИВ  ← на всю ширину (от края ПРОДАНО до края В РАБОТЕ)   │
└─────────────────────────────────────────────────────────────┘
```

---

## 1. Верхний ряд (KPI)

- **4 маленькие карточки** одинакового размера
- Расположены **горизонтально** в один ряд
- Одинаковые отступы между ними
- Скруглённые углы (rounded-rectangle)

---

## 2. Основная зона (3 колонки)

### Левая колонка — ПРОДАНО
- **Высокий вертикальный блок**
- Заголовок «ПРОДАНО» вверху
- Остальное пространство — список проданных проектов (или пусто)
- Проекты можно перетаскивать сюда из недель

### Центральная зона — НЕДЕЛИ
- **4 горизонтальных блока** друг под другом
- Сверху вниз: **Неделя 4** → **Неделя 3** → **Неделя 2** → **Неделя 1**
- Каждый блок — горизонтально вытянутый (elongated)
- **Пунктирные края** (dashed) — визуально показывают, что элементы можно перетаскивать в ПРОДАНО или В РАБОТЕ

### Правая колонка — В РАБОТЕ
- **Высокий вертикальный блок** (зеркало левой)
- Заголовок «В РАБОТЕ» вверху
- Список проектов в работе
- Проекты можно перетаскивать сюда из недель

### Соотношение колонок
- ПРОДАНО и В РАБОТЕ — **равная ширина** (или по потребности)
- Центр с неделями — между ними, **по ширине 4-х недель**

---

## 3. Нижняя зона — АРХИВ

- **Один широкий горизонтальный блок**
- Текст «АРХИВ» в заголовке
- **Ширина = от левого края ПРОДАНО до правого края В РАБОТЕ** (по ширине 4 недель)
- Расположен строго под основной зоной

---

## 4. Ключевые правила

1. **ПРОДАНО и В РАБОТЕ** — в **одной строке** по горизонтали, слева и справа от недель.
2. **4 недели** — в **центре**, вертикальный столбик между колонками.
3. **АРХИВ** — строго **под ними**, на всю ширину.
4. В **верхнем меню/KPI** — показывать: сколько продано (количество + сумма).
5. В проектах **ПРОДАНО** и **В РАБОТЕ** — **редактируемая цена** (клик по сумме).
6. **Без внешних рамок** у блоков (минималистичный вид).

---

## 5. Элементы в карточке проекта (ПРОДАНО / В РАБОТЕ)

- Дата (слева)
- Круглый аватар (emoji)
- Название проекта
- Зелёная сумма (редактируемая, клик = popup)
- Кнопка × (удалить)

---

## Использование промпта

Скопируй этот документ и используй как ТЗ при реализации или доработке страницы ЦЕЛИ. Layout должен строго соответствовать этой схеме.
