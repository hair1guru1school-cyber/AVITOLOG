# ПРОМПТ: Вкладка ЦЕЛИ — строго по макету

## ИСХОДНИЕ ДАННЫЕ
- Два макета: (1) визуальный скрин с карточками клиента; (2) wireframe с блоками ПРОДАНО | НЕДЕЛИ | В РАБОТЕ | АРХИВ
- Стиль: тёмный neon SaaS (наш)
- Вкладка ЦЕЛИ должна открываться по умолчанию при входе в режим целей

---

## ЧАСТЬ 1. WIREFRAME — СТРУКТУРА СТРАНИЦЫ

### ROW 0 — Верхняя строка (4 KPI-карты)
- 4 одинаковых компактных блока в один горизонтальный ряд
- Равная ширина, равные отступы между ними
- Содержимое каждого блока:
  1. **НОВЫХ** — число новых проектов в неделях
  2. **В РАБОТЕ** — число активных сделок
  3. **ПРОДАНО** — число проданных + сумма в ₽
  4. **ВОРОНКА** — общая сумма воронки (P)
- Стиль: тёмный фон, тонкая обводка (1px), скругление 8px, компактные цифры

### ROW 1 — Главный контент (три колонки в одну линию)

**Колонка ЛЕВАЯ — ПРОДАНО**
- Ширина: ~240px (фиксированная или min-width)
- Заголовок: «☑ ПРОДАНО»
- Список проданных сделок: Дата | Аватар | Имя | Зелёная сумма ₽ | ×
- Внизу блока: итоговая сумма
- Кнопка «+ Добавить проект»
- Стиль: тёмный блок, скругление 12px, фиолетовая подсветка границы

**Колонка ЦЕНТР — НЕДЕЛИ**
- Ширина: flexible (1fr), занимает основное пространство
- 4 блока друг под другом, порядок сверху вниз: **4** → **3** → **2** → **НЕДЕЛЯ 1**
- Каждый блок недели: заголовок «N НЕДЕЛЯ», таблица (Дата | Проект | КП | Статусы | Касания | X), кнопка «+ Добавить»
- Стиль: тёмный блок, скругление 10px, голубая подсветка заголовков

**Колонка ПРАВАЯ — В РАБОТЕ**
- Ширина: ~240px (зеркало левой)
- Заголовок: «🔥 В РАБОТЕ»
- Список активных сделок: Дата | Аватар | Имя | Зелёная сумма ₽ | ×
- Внизу: «ОБЩИЙ ПОТЕНЦИАЛ: X ₽»
- Кнопка «+ Добавить проект»
- Стиль: тёмный блок, скругление 12px, оранжевая подсветка границы

### ROW 2 — АРХИВ
- Один блок на всю ширину страницы
- Расположен под тремя колонками
- Заголовок: «📁 АРХИВ»
- Список архивных проектов
- Стиль: такой же как у блоков НЕДЕЛИ (широкий, на всю ширину)

---

## ЧАСТЬ 2. ПОРЯДОК КОЛОНОК (СЛЕВА НАПРАВО)
1. **ПРОДАНО** (слева)
2. **НЕДЕЛИ** (центр, широкая)
3. **В РАБОТЕ** (справа)
4. **АРХИВ** (внизу, full width)

---

## ЧАСТЬ 3. ВИЗУАЛЬНЫЙ СТИЛЬ («НАШ СТИЛЬ»)

### Цвета
- Фон страницы: тёмный градиент (#0c0c0e, rgba)
- Блоки: rgba(255,255,255,0.02)–0.04, граница rgba(255,255,255,0.05–0.08)
- ПРОДАНО: border rgba(230,94,255,0.2), hover-подсветка
- В РАБОТЕ: border rgba(255,107,53,0.2), hover-подсветка
- НЕДЕЛИ: border rgba(53,208,255,0.15)
- Зелёная сумма: linear-gradient(#00e687, #00c873), тень
- Текст: #ebebeb, muted #666

### Скругления
- Блоки ПРОДАНО/В РАБОТЕ: 12px
- Блоки недель: 10px
- Строки внутри: 8px
- Зелёная сумма: 8px
- Кнопки: 8px

### Тени и глубина
- Блоки: box-shadow 0 4px 20px rgba(0,0,0,0.15)
- Hover: 0 6px 24px rgba(0,0,0,0.2)
- Зелёная сумма: 0 2px 8px rgba(0,217,126,0.25)

### Шрифты
- Заголовки блоков: 11–12px, font-weight 800
- Строки: 11px
- Суммы: 11px, font-weight 800
- Семейство: Golos Text

---

## ЧАСТЬ 4. КОМПАКТНОСТЬ (КАК В EXCEL)
- Строки: min-height 24–28px
- Невысокие блоки, всё видно на экране
- Минимум пустого пространства, плотная сетка

---

## ЧАСТЬ 5. ПОВЕДЕНИЕ
- Вкладка ЦЕЛИ открыта по умолчанию при заходе в раздел целей
- Клик по строке — открыть редактирование проекта
- Зелёная сумма — кликабельна, редактирование
- Кнопки ✓ / 🔥 / 🗂 — перенос между ПРОДАНО / В РАБОТЕ / АРХИВ
- × — удалить

---

## ЧАСТЬ 6. АДАПТИВ
- &gt;1000px: 3 колонки [ПРОДАНО | НЕДЕЛИ | В РАБОТЕ]
- 560–1000px: 2 колонки сверху, НЕДЕЛИ на всю ширину ниже
- &lt;560px: всё в один столбец
