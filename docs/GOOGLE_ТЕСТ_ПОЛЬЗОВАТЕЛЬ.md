# Как убрать экран «Эксперты Google не проверяли это приложение»

## Главное решение (в Google Cloud Console)

Чтобы **не видеть** этот экран при каждом входе:

1. Открой: https://console.cloud.google.com/
2. Выбери проект с OAuth-клиентом AVITOLOG (разработчик: hair1guru1school@gmail.com)
3. Перейди: **APIs & Services** → **OAuth consent screen**
4. Прокрути до раздела **Test users**
5. Нажми **+ ADD USERS**
6. Добавь свой Gmail (тот, которым заходишь в приложение)
7. Сохрани

После этого при входе экран предупреждения должен быть короче, а повторные входы — быстрее.

---

## Решение частых ошибок OAuth

| Ошибка | Причина | Что делать |
|--------|---------|------------|
| **interaction_required** | Google требует выбор аккаунта или подтверждение | Нажимаешь «Войти» → сразу показывается окно выбора аккаунта. Выбери нужный Gmail. |
| **access_denied** | Отказано в доступе или закрыто окно | Нажми «Войти» снова и подтверди доступ к Drive и Таблицам. |
| **popup_closed** | Окно входа закрыли до завершения | Просто нажми «Войти» ещё раз. |
| **401 / invalid credentials** | Токен истёк | Нажми 🔑 Drive (или «Войти») и авторизуйся заново. |
| **Пустая папка** в CRM | Часто = 401 (токен протух) | Повтори вход через Drive, затем открой CRM снова. |

## Что изменено в коде (06.03, 10.03.2026)

1. **При нажатии «Войти»** — сразу показывается окно выбора аккаунта (раньше был «тихий» режим, дававший interaction_required).
2. **401 / Сессия истекла** — при ошибках Drive сбрасываем токен и показываем понятное сообщение.
3. **Бэкап** — `backups/index_06_03_2026_BEFORE_OAUTH_FIX.html` (если нужно откатиться).
