# РАЗДЕЛЕНИЕ ПРОЕКТА НА 5–8 ОСНОВНЫХ ПАКЕТОВ

## Рекомендуемый вариант (8 пакетов)
1. **core** — запуск приложения, глобальное состояние, маршрутизация вкладок.
2. **ui** — рендер компонентов и popups.
3. **crm** — сущности клиентов, выбор, сохранение, фильтрация.
4. **goals** — недельная воронка, статусы, суммы, архив.
5. **integrations** — Google Drive/API и внешние подключения.
6. **storage** — local/session storage, миграции ключей.
7. **shared** — утилиты, форматтеры, константы, общие типы.
8. **styles** — темы, переменные, layout и component styles.

## Если нужен компактный вариант (6 пакетов)
- core, ui, crm, goals, integrations, shared
(при этом storage и styles остаются подпакетами shared)

## Правила границ
- ui не знает про integrations напрямую — только через сервисы core.
- crm/goals не импортируют друг друга напрямую: общение через core/shared.
- storage не содержит бизнес-правил.
- integrations не рендерят UI.

## Минимальный порядок переноса
1) styles → 2) core → 3) storage → 4) crm → 5) goals → 6) integrations → 7) ui cleanup → 8) docs/release.
