# Папка «ОБНОВИТЬ_САЙТ»

Содержит:
- `ОБНОВИТЬ САЙТ.bat` — батник для pull/add/commit/push.
- `СОЗДАТЬ_ЯРЛЫК.vbs` — создание ярлыка на рабочем столе (`ОБНОВИТЬ САЙТ.lnk`).

## Как использовать
1. Дважды кликните `СОЗДАТЬ_ЯРЛЫК.vbs` (один раз).
2. На рабочем столе появится ярлык `ОБНОВИТЬ САЙТ.lnk`.
3. Через ярлык запускайте батник для обновления.

## Важно
- Нужен установленный Git.
- Нужно быть авторизованным в Git (SSH/HTTPS credentials).
