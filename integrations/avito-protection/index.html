Сбор статистики и возможности

Карантин пока фиксирует ID объявления, но не снимает его с Авито: архивация через API не подключена. Это ограничение действий, а не признак отсутствия просмотров.

График показывает подозрительные скачки, не все просмотры. Измерение — один полный срез просмотров и контактов карточки; это не число уникальных объявлений. Пропущенные счётчики API не считаются нулём.

Файл, копии и диагностика облака

Перед заменой сохраняется полная копия. Меняется только Title по точному AvitoId; Id, цены и остальные данные остаются прежними. При конфликте обновление останавливается. Авито прочитает файл при следующей автозагрузке, не мгновенно. Новые заголовки задаются ниже.

Алгоритм сигналов

Остановка автозагрузки пока не подключена. Для применения обновлённого исходного файла нужна действующая автозагрузка.

Статистика поступает накопительными дневными счётчиками. Интервал 5–15 минут — время между наблюдениями; задержка API не позволяет доказать время каждого просмотра или вероятность скрутки.

Цепочка файла: сигнал → запись ID в карантин → копия → изменение Title → проверенная загрузка в облако.
